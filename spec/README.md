# Specifications

- [content-format.md](content-format.md): the files and folders DocuWaves
  reads and writes in a content repository. Version 1.0, as of DocuWaves 2.3.
- [conformance/](conformance/): content trees with the result a reader must
  get from each. They are how a reader, DocuWaves' own or any other, shows
  that it follows the spec.

A reference checker is in [tools/docuwaves-lint](../tools/docuwaves-lint/).
